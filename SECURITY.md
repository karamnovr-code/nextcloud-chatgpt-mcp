# Security policy

Do not publish production configuration, OAuth credentials, signing keys,
tokens, cookies, callback query strings, SSH keys, database dumps, job inputs,
or real document contents.

Report suspected vulnerabilities privately through GitHub Security Advisories.
Include a minimal synthetic reproducer and affected version. Do not test against
systems or data you do not own or have explicit permission to assess.

This project parses untrusted document formats through third-party libraries.
Its sandbox and allowlists reduce risk but are not a formal security guarantee.
